# customer-behavior-analysis-dashboard
Customer Behavior Analysis | Python • SQL • Power BI | Data cleaning, analysis, visualization, and business insights.

##  Overview

This project analyzes customer purchasing behavior using **Python, SQL, and Power BI**. It includes data cleaning, exploratory data analysis (EDA), SQL-based business queries, and an interactive dashboard to uncover customer trends and generate actionable business insights.

##  Tools Used

* Python
* SQL Server / PostgreSQL
* Power BI

##  Project Steps

1. Data Loading & Cleaning
2. Exploratory Data Analysis (EDA)
3. SQL Querying & Business Analysis
4. Dashboard Development in Power BI
5. Report & Presentation Creation

## Dashboard Highlights

* Sales & Revenue Analysis
* Customer Segmentation
* Product Performance
* Purchase Trends
* Interactive Filters & KPIs

##  Key Outcomes

* Identified high-value customers
* Analyzed purchasing patterns
* Discovered top-performing products
* Generated data-driven business recommendations

##  How to Run

1. Open the Jupyter Notebook and run the analysis.
2. Execute SQL queries in SQL Server/PostgreSQL.
3. Open the `.pbix` file in Power BI Desktop to view the dashboard.
